# Resume - Kavita J. Bhartiya

This is a personal resume webpage of Kavita J. Bhartiya, a software engineer with over 9 years of experience. The webpage is structured in HTML, styled with CSS, and includes a functionality to download the resume as a PDF, excluding the download button itself.

## Features

- **Download Resume as PDF:** A button at the bottom of the page allows the user to download the resume in PDF format, excluding the download button from the document.
- **Styled Header Message:** A header message at the top provides a thank you note and a link to the latest resume.
- **Responsive Design:** The webpage is designed to be responsive and looks good on various devices.
- **Minimalistic and Professional Layout:** The layout is clean, using a simple color scheme and easy-to-read typography.

## Technologies Used

- **HTML** - Structure of the webpage
- **CSS** - Styling of the webpage
- **jsPDF** - JavaScript library to generate the PDF from the HTML content
- **JavaScript** - For handling the click event and PDF generation
